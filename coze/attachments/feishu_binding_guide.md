# 飞书渠道绑定教程

## 适用场景
在 Coze 平台绑定飞书，使 Agent 可通过飞书与用户双向对话。

## 操作步骤

### 第一步：向 Agent 发送指令
```
绑定飞书
```
或
```
连接飞书
```

### 第二步：Agent 自动完成
Agent 会自动调用 `feishu_auth_and_create` 工具，流程如下：

1. 检查当前渠道是否已有飞书绑定
2. 若无绑定，返回飞书授权链接
3. 用户点击授权链接，完成飞书应用授权
4. 系统自动创建飞书应用并完成绑定

### 第三步：验证绑定
绑定成功后，可通过飞书向 Agent 发送消息进行测试。

## 注意事项
- 每个 Coze Agent 只能绑定一个飞书渠道
- 绑定后，Agent 在飞书的消息也会同步到 Coze 对话
- 飞书授权需要用户本人操作

## 故障排除
| 问题 | 解决方案 |
|------|----------|
| 授权链接打不开 | 检查飞书账号是否是企业版/专业版 |
| 提示"已绑定" | 当前 Agent 已绑定飞书，无需重复绑定 |
| 消息收不到 | 检查飞书机器人是否被拉入对话 |
